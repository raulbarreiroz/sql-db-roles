# SQL / DB Admin - Junior

## Definition
Escribe consultas SQL con joins complejos, subconsultas y CTEs. Crea tablas, índices básicos y gestiona backups sencillos en entornos cloud (RDS).

## Specific Project
Diseño e importación de un CRM de clientes y pedidos desde Excel a PostgreSQL, creando relaciones y generando reportes mensuales de ventas.

## Core Concepts
DDL (CREATE TABLE, ALTER, CONSTRAINTS PK/FK), DML (INSERT, UPDATE, DELETE), JOINs (INNER, LEFT, RIGHT), GROUP BY + funciones agregadas (SUM, COUNT), índices B-tree básicos, herramientas GUI (DBeaver/pgAdmin).

## Recommended Modern Technologies
PostgreSQL 17, pgAdmin 4 / DBeaver, Azure Data Studio, AWS RDS, Aiven.
